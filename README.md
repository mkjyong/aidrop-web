# AiDrop-web

AiDrop은 블록체인 주소를 제출하고 관리하는 간단한 웹 애플리케이션입니다. 사용자가 다양한 블록체인의 지갑 주소를 제출할 수 있는 플랫폼을 제공합니다.

## 기능

- 다양한 블록체인 지원 (EVM 및 비EVM 체인)
- 사용자 지갑 주소 제출 및 저장
- 주소 유효성 검사
- 반응형 사용자 인터페이스
- **유저별 온체인 활동 분석 보고서** (신규)
- **체인별 종합 데이터 대시보드** (신규)

## 기술 스택

- **프론트엔드**: Next.js 15, React 19, TypeScript
- **스타일링**: Tailwind CSS
- **데이터베이스**: Supabase
- **배포**: Vercel
- **데이터 시각화**: Chart.js, D3.js

## 시작하기

### 사전 요구사항

- Node.js 20.x 이상
- npm 또는 yarn
- Supabase 계정 및 프로젝트

### 설치

1. 저장소 복제:
   ```bash
   git clone https://github.com/your-username/AiDrop-web.git
   cd AiDrop-web
   ```

2. 종속성 설치:
   ```bash
   npm install
   ```

3. 환경 변수 설정:
   `.env.local` 파일을 생성하고 다음 내용을 추가하세요:
   ```
   NEXT_PUBLIC_SUPABASE_URL=your-supabase-url
   NEXT_PUBLIC_SUPABASE_ANON_KEY=your-supabase-anon-key
   ```

4. 개발 서버 실행:
   ```bash
   npm run dev
   ```

## 데이터베이스 설정

Supabase 프로젝트에서 다음 테이블을 생성하세요:

### user_submissions 테이블
- `id`: uuid (기본 키)
- `created_at`: timestamp with time zone
- `chain_id`: text
- `address`: text
- `ip_address`: text (선택 사항)
- `is_evm`: boolean
- `chain_name`: string
- `status`: string
- `updated_at`: timestamp with time zone

## 새로운 기능 기획

### 1. 유저별 온체인 활동 분석 페이지

#### 기능 개요
- 개별 사용자가 제출한 주소의 온체인 활동을 시각화하여 분석 결과를 보여주는 페이지
- 고유한 "데이터 포트레이트" NFT 형태로 사용자의 활동 패턴 표현
- 사용자 주소에 대한 상세 분석 데이터 제공

#### 주요 기능 요소
- **NFT 데이터 포트레이트**: 사용자의 온체인 활동을 시각화한 고유 그래픽
- **활동 타임라인**: 사용자의 주요 트랜잭션과 상호작용 히스토리
- **포트폴리오 분석**: 보유한 자산 유형 및 가치 분포
- **활동 패턴**: 주간/월간 활동 패턴 시각화
- **유사 사용자 비교**: 유사한 활동 패턴을 가진 다른 사용자와의 비교
- **소셜 공유**: 분석 결과를 소셜 미디어에 공유하는 기능

#### 데이터 흐름
1. 사용자가 지갑 주소 제출
2. 백엔드에서 온체인 데이터 수집 및 분석
3. 분석 결과를 시각화하여 사용자에게 제공
4. NFT 데이터 포트레이트 생성 및 민팅 옵션 제공

#### 디자인 가이드라인
- 모던하고 미니멀한 UI 디자인
- 직관적인 데이터 시각화
- 애니메이션과 인터랙티브 요소를 통한 사용자 경험 향상
- 다크/라이트 모드 지원

### 2. 체인별 종합 데이터 대시보드

#### 기능 개요
- 각 블록체인별 제출된 주소 데이터를 종합하여 인사이트 제공
- 플랫폼 전체의 활동 추세와 패턴 시각화
- 체인 간 비교 분석 기능

#### 주요 기능 요소
- **체인별 활동 지표**: 각 체인의 활동량, 사용자 수, 트랜잭션 볼륨 등 시각화
- **지역별 분포**: 지역에 따른 체인 사용 패턴 분석
- **시간대별 추세**: 일일/주간/월간 활동 추세 차트
- **체인 간 비교**: 여러 체인의 주요 지표를 비교할 수 있는 대시보드
- **실시간 데이터 업데이트**: 주기적으로 업데이트되는 실시간 데이터
- **필터링 옵션**: 다양한 기준으로 데이터를 필터링하는 기능

#### 데이터 흐름
1. 모든 사용자 제출 데이터 수집
2. 체인별, 시간별, 지역별 등 다양한 기준으로 데이터 집계
3. 데이터 시각화 및 인터랙티브 대시보드 생성
4. 정기적인 데이터 업데이트 및 새로운 인사이트 제공

#### 디자인 가이드라인
- 직관적이고 정보가 풍부한 대시보드 레이아웃
- 다양한 차트 및 그래프 활용 (막대 차트, 라인 차트, 히트맵, 산점도 등)
- 필터 및 검색 기능을 통한 데이터 탐색 용이성
- 반응형 디자인으로 모바일 장치에서도 최적의 경험 제공
